# 五子棋游戏

AI执黑先行的五子棋游戏，支持图形界面和终端两种模式。

## 游戏规则

- AI执黑子，先手
- 玩家执白子
- 先连成五子者获胜

## 运行方式

### 图形界面版本 (推荐)

```bash
# 安装依赖
pip install pygame numpy

# 运行游戏
python gomoku.py
```

**操作说明：**
- 鼠标点击落子
- 按 `R` 重新开始
- 按 `Q` 退出游戏

### 终端版本

```bash
# 安装依赖
pip install numpy

# 运行游戏
python gomoku_terminal.py
```

**操作说明：**
- 输入坐标落子，格式：`行 列`（如 `7 7`）
- 输入 `q` 退出游戏

## AI算法

AI使用以下技术：

1. **极大极小算法 (Minimax)** - 搜索最优落子
2. **Alpha-Beta剪枝** - 优化搜索效率
3. **棋型评估** - 评估连五、活四、冲四、活三等棋型
4. **候选点优化** - 只搜索已有棋子周围的位置

## 文件说明

- `gomoku.py` - 图形界面版本（需要pygame）
- `gomoku_terminal.py` - 终端版本（纯文本）
- `requirements.txt` - 依赖列表

## 技巧提示

1. 尽量抢占中心位置
2. 注意防守AI的活三
3. 尝试创造双活三或四三连攻
4. AI会优先考虑进攻和防守，找到它的弱点
